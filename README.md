# DT200G Laboration 1.2 - Bildredigering

Detta var en universitetsuppgift med syftet att:
> * Förstå grundläggande begrepp gällande bildbehandling.
> * Lära sig grunderna i bildbehandling och kunna implementera dom praktiskt.

Uppgiften gick ut på att "Skapa en webbplats som presenterar ett antal givna bilder. Bilderna ska behandlas så att de är enhetliga med varandra och webbplatsen."
